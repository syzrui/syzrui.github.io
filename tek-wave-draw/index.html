使用说明

加载波形

点击「打开 ISF」或把文件拖到波形区，支持一次选择四个通道（CH1–CH4）。文件只在本地浏览器内解析，不会上传到任何服务器，断网也能用。点「示例数据」可加载随附的四通道样例。

鼠标 / 触屏

  • 滚轮：以鼠标当前所在时间点为锚点缩放时间轴（锚点对应时间严格不变）；Shift + 滚轮：平移。
  • 时间窗口最大就是整段波形：加载后即处于该状态，继续向下滚动不会再缩小，也不会出现比数据更宽的时间轴；此时拖动同样不会把窗口移出数据范围（需要左右移动请先放大）。
  • 拖拽：平移；Alt + 拖拽（或右键拖拽）：框选放大；双击：适应全部。
  • 在底部时间刻度条上左右拖选，可直接把横轴缩放到该宽度。
  • 「固定档位」模式下，通道卡片上的 − / + 调整 V/div，滑杆调整垂直位移。
  • 开启「光标」后拖动 X1 / X2 竖线（指针移到线上会变成左右箭头）。两条光标锚定在绘图区像素位置：缩放、平移时屏幕位置不变，对应的实际时间与测量值实时重算。
  • 右侧「光标」面板给出 X1/X2 时间、ΔT、周期 T、频率 f，以及各通道 Y@X1、Y@X2、ΔY、X1→X2 区间均值（区间内采样点平均，宽区间等间隔抽样）；f = 1/|ΔT| 只代表当前光标间隔的倒数，跨一个完整周期时才等于信号频率。
  • 触屏：单指平移，双指捏合缩放。

快捷键

  • + / − 缩放，← / → 平移，R 适应
  • C 光标，G 栅格，H 读数，Z 框选
  • 1–4 切换当前通道，空格 切换分道 / 叠加

支持的文件

泰克 ISF / WFM 波形：ENCDG BINARY（8 / 16 / 32 / 64 位，RI / RP / FP，MSB / LSB）或 ASCII；按 XINCR / XZERO / PT_OFF 还原时间轴，按 YMULT / YOFF / YZERO 还原电压（或电流）。

提示：单通道 1000 万点的 ISF 约 20 MB，四通道共 80 MB，加载与首次建索引需要一两秒。
