使用说明

加载波形

点击「打开 ISF」或把文件拖到波形区，支持一次选择四个通道（CH1–CH4）。文件只在本地浏览器内解析，不会上传到任何服务器，断网也能用。点「示例数据」可加载随附的四通道样例。

鼠标 / 触屏

  • 滚轮：以指针为中心缩放时间轴；Shift + 滚轮：平移。
  • 拖拽：平移；Alt + 拖拽（或右键拖拽）：框选放大；双击：适应全部。
  • 「固定档位」模式下，通道卡片上的 − / + 调整 V/div，滑杆调整垂直位移。
  • 开启「光标」后拖动 X1 / X2 竖线（指针移到线上会变成左右箭头），右侧给出每条光标处的 Y 值、ΔY 与区间平均值。
  • 触屏：单指平移，双指捏合缩放。

快捷键

  • + / − 缩放，← / → 平移，R 适应
  • C 光标，G 栅格，H 读数，Z 框选
  • 1–4 切换当前通道，空格 切换分道 / 叠加

支持的文件

泰克 ISF / WFM 波形：ENCDG BINARY（8 / 16 / 32 / 64 位，RI / RP / FP，MSB / LSB）或 ASCII；按 XINCR / XZERO / PT_OFF 还原时间轴，按 YMULT / YOFF / YZERO 还原电压（或电流）。

提示：单通道 1000 万点的 ISF 约 20 MB，四通道共 80 MB，加载与首次建索引需要一两秒。
